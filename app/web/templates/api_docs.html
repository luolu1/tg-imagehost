认证

在 Telegram 向机器人发送 /token 获取你的 API Token，然后在请求头中携带（二选一）：

Authorization: Bearer <token>
X-API-Token: <token>

基础地址：{{ api_base }} · 交互式文档：/docs、/redoc、 /openapi.json

POST/api/upload

上传单张图片（multipart/form-data，字段名 file）。单文件上限 {{ max_mb }} MB，受用户配额限制。

curl -X POST "{{ api_base }}/upload" \ -H "Authorization: Bearer YOUR_TOKEN" \ -F "file=@photo.png"

GET/api/me

获取当前用户信息（用量、配额）。

curl "{{ api_base }}/me" -H "Authorization: Bearer YOUR_TOKEN"
GET/api/images

分页列出我的图片（最新在前）。查询参数：limit（1-200，默认 50）、offset（默认 0）。

curl "{{ api_base }}/images?limit=20&offset=0" \ -H "Authorization: Bearer YOUR_TOKEN"
DELETE/api/images/{id}

删除指定图片。普通用户只能删自己的，管理员可删任意图片。

curl -X DELETE "{{ api_base }}/images/ab12cd" \ -H "Authorization: Bearer YOUR_TOKEN"
POST/api/images/bulk-delete

按 ID 列表批量删除。请求体为 JSON：{"ids": ["id1", "id2"]}。

curl -X POST "{{ api_base }}/images/bulk-delete" \ -H "Authorization: Bearer YOUR_TOKEN" \ -H "Content-Type: application/json" \ -d '{"ids": ["ab12cd", "ef34gh"]}'
